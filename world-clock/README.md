# ATELPIX World Clock

A standalone Windows desktop world clock with an offline time-zone database.

## Features
- Live clocks for Dhaka, New York, London, Toronto, Amsterdam, Sydney, Auckland, Tokyo and Dubai.
- Add and remove time zones.
- 12-hour / 24-hour display.
- Automatic daylight-saving and UTC-offset handling.
- Saves the selected city list locally.
- Dark navy interface with cyan / blue / purple accents.

## Download the Windows app
The GitHub Actions workflow builds a self-contained Windows executable. Open the repository's **Actions** tab, select **Build ATELPIX World Clock for Windows**, then download the **ATELPIX-World-Clock-Windows** artifact from a successful run. Extract the ZIP and double-click `ATELPIX-World-Clock.exe`. No Python installation is needed.

The app uses a bundled time-zone database and does not need an internet connection to display time after installation.
